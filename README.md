# Rajhansh Transport Management System

A full-stack MERN (MongoDB, Express, React, Node.js) project for managing transport company operations.

## Tech Stack
- Frontend: React + Tailwind CSS
- Backend: Node.js + Express
- Database: MongoDB
- Auth: JWT

## Features
- Driver Login & Dashboard  
- Trip Management  
- Fuel Logs (Quantity, Cost, Efficiency)  
- Maintenance Logs  
- Truck Management  
- Image Uploads (Multer)
- Owner/Admin Dashboard

## Project Structure
Transport_Management_System/
│
├── frontend/      → React frontend
└── server/        → Node.js backend API
